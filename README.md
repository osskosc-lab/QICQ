# QICQ

QICQ is maintained as a falsification-first research framework.

## Current active line

**H_QC Phase 1 — Xenon Isotope Replication**

The current confirmatory target is deliberately narrow: independently test whether a xenon-isotope-dependent anesthetic phenotype replicates under a frozen, blinded, blocked design before any stronger quantum-mechanism or consciousness claim is considered.

This repository separates:

1. preregistered claims and stopping rules,
2. computational design audits and simulation,
3. later real-world data analysis,
4. interpretation / claim ceilings.

No synthetic result in this repository is evidence for a biological or quantum-consciousness mechanism.
